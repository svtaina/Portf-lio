# 💼 Portfólio / Currículo Web

## 📋 Descrição

Desenvolvimento de uma página de **Portfólio / Currículo Web** utilizando **HTML5 semântico**, com informações pessoais, habilidades, projetos e formulário de contato.

## 🎯 Objetivo

Praticar a estruturação de páginas web utilizando elementos semânticos e recursos básicos do HTML5.

## 🛠️ Tecnologias

* HTML5
* Tabelas
* Formulários
* Links internos
* Elementos semânticos

## 📌 Conteúdo da Página

* Cabeçalho e menu de navegação.
* Seção **Sobre Mim** com foto e habilidades.
* Seção **Meus Projetos** com tabela.
* Formulário de **Contato**.
* Rodapé com e-mail, telefone e direitos autorais.

## ✅ Conclusão

A atividade ajudou a praticar a criação de uma página web organizada e semântica, utilizando diferentes recursos do HTML5 para apresentar informações de forma clara e funcional.
